## v2.6.1 及更早版本：请手动升级

`v2.6.1` 及更早版本的客户端**用不了自动升级**。这批版本内置的替换脚本缺三项修正（CRLF 落盘、绝对路径、等待次数上限），`texttool update` 会卡在等待环节，不报错也不完成。替换脚本由客户端自己写出，修好的版本回溯不到已经发出去的旧客户端。

**这类用户请手动升级**：从本 Release 下载 `TextTool-GUI-<版本>-win-x64.zip`（或 CLI 包），解压覆盖原目录即可。

`v2.6.2` 及之后版本的自动更新正常。

## v3.0.1：图形界面重写

- **图形界面整体重写**，Windows 与 Linux 都有。此前 Linux 只有命令行版。
- **深色模式全局生效**：页签、按钮、下拉框、输入框、对话框都跟着变，不再出现系统浅色块。
- **切语言立即生效**，不用重启；检查报告的正文也跟着界面语言走，不再固定中文。
- **视觉小说单文件改为先预览、点保存才写盘**，关掉预览窗则磁盘不变。
- **AI 味检查恢复「只跑规则」筛选**，与命令行的只跑指定规则对应。
- **关于页补齐**：图标、头像、版本、仓库链接、配置导入导出、检查更新。

已知边界：图形界面只检查有没有新版本，不自动替换；自动更新仍然只在命令行版上提供。

## v3.0.0：升级后能感觉到的变化

- **人读报告的行尾统一成 LF**。
- **命中行末尾多一个 `<- 方案：<名>` 提示**，一眼看出命中的是哪条规则。
- **报告分组改为按各组首次命中的位置排**。
- **段落判定自动化**：`lint` 按文本里空行的占比自己判断是 Markdown 还是纯文本，并在报告的 `[NOTE]` 行里说明判成了哪种，不用再手工指定。
- **`--min-severity` 不再区分大小写**，`High`、`high` 都认。
- **规则码换了名字**：从 `P1`、`S5`、`C1` 这类短码，换成 `repeated-punctuation` 这样的可读名字，报告里同时给出中文标题。用 `--only` 时按新名字写。
- **自定义规则文件变严格**：`lint_rules.json` 里如果定义了程序内置的算法规则 Id（`P4`、`P5`、`C1` 到 `C6`），启动时会直接报错，不再静默接受（原先会让同一个 Id 既有算法命中又有数据命中，报告里冒出重复 Id）。删掉那几个冲突条目即可。

## Linux：界面与命令行

Release 里 Windows 与 Linux 各有图形界面和命令行两份包，共四份。

Linux 上需要先装 .NET 8 运行时与 Noto 的 CJK 字库；zip 不保留可执行位，解压后要给可执行文件加执行权限。具体命令见 README 的 Linux 一节。

界面版只检查更新、不自动替换；命令行版的 `update` 在 Linux 上也只能查询（`--check`），升级请下载新包手动覆盖目录。
