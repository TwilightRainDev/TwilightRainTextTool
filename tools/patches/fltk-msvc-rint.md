# 用微软编译器重建 FLTK 时要改的一行

FLTK 1.4.5 的 `FL/math.h` 第 44 行有一段兜底：编译器没有 `rint` 时自己写一个。
微软现在的编译器自带的运行库里已经有同名同参数的函数，两边一起链接就是
`LNK2005: rint 已经在 fltk.lib 中定义`，界面版链接不过。

改法：把那段兜底的条件加上「编译器不是微软那家才启用」，也就是

```c
#if !defined(_MSC_VER) && <原来的条件>
```

改完重编 FLTK 再链接。这处改在 FLTK 源码里，不在本工程里，所以单独记一份。

另一条路是不改 FLTK、给链接器加强制多重定义开关，但那会让程序用的取整规则从
「半数取偶」变成「半数一律进位」，与对照基准的行为不一致，不要用。
